# Flipkart Pricing Analysis

## Project Overview
This project analyzes Flipkart product pricing using Python and Power BI.

## Files
- `maincode.py` – Python script for data processing and analysis.
- `dataset.csv` – Raw dataset.
- `pricing_analysis.csv` – Processed dataset.
- `Flipkart_Pricing_Analysis.pbix` – Power BI dashboard.

## Tools Used
- Python
- Pandas
- NumPy
- Power BI

## How to Run
1. Install Python and the required libraries.
2. Run `maincode.py`.
3. Open `Flipkart_Pricing_Analysis.pbix` in Power BI Desktop to view the dashboard.
